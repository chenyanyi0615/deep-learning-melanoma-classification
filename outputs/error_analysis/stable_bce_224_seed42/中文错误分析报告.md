# 原 ResNet-50 模型：验证集错误分析

本报告使用第二轮 stable_bce_224_seed42 的冻结预测。没有训练、没有重新推理、没有读取测试集成绩，没有改动标签或删除图像。
分析对象是已反复使用的验证集，属于探索性分析，不能当作新的独立测试。
图册中的P是模型sigmoid输出分数，未校准，不能直接解释为患癌概率。
验证集：4620 张、308 位患者，84 张黑色素瘤来自 64 位患者。阈值固定为 0.00988064426929，采用 >= 判为阳性。
复现结果：TP=76、FN=8、FP=1041、TN=3495；敏感度90.48%，特异度77.05%，AUROC=0.8956。

## 漏检图像初查
8张漏检来自8位患者；来源分布为 Barcelona 3、MSK 1、Queensland 1、Vienna 3。
已经逐张查看原图缩略图与实际224像素输入。部分有毛发或笔迹、部分视觉对比较弱，但也有中心深色或红色区域清楚可见的图像。
不存在已确认、能统一解释8张漏检的外观特征；不能直接断言提高分辨率或去毛发就能修复。
逐图观察见 visual_observations.json；这些是工程外观描述，不构成临床判读或标签复核。

## 误报与正确样本对照
误报涉及232位患者。误报最多的前5位患者贡献115张，占全部误报11.05%；前10位贡献195张，占18.73%。
因此误报并非只由少数患者造成。前5位共有197张良性图像，解读误报数时也应考虑各患者图像数不同。
将误报按得分高低划分三等份，各抽12张且共36位不同患者；另抽16位患者的TN及16位患者的TP。
抽样采用固定种子42，每组每位患者最多1张；TP/TN抽样独立进行，因此不同组可能有同一患者。
图册是定性对照，不能从抽样图册估计毛发等特征的全体比例。毛发、刻度、圆形视野及笔迹在正确和错误组都可见，不能仅凭存在这些特征判定因果。

## 次要分组线索
头颈部误报89/246（36.18%），下肢211/1156（18.25%）；80岁以上51/83（61.45%），40岁以下215/1038（20.71%）。
这些都是图像级、未调整的描述统计，并不证明年龄或部位是原因，也不支持直接设置分组阈值。
原图长宽比估算的填充面积15%—30%组误报428/846（50.59%），30%—45%组599/3674（16.30%）。
填充比例是长宽比的近似代理，不是病灶面积；与来源相关，不能据此认定灰色填充导致误报。
已保存 source_padding_cross_statistics.csv 供交叉检查。各分组患者可能重叠，不能将分组患者数相加。
4536张良性图像中3861张（85.12%）的具体诊断为unknown；1041张误报中862张没有具体良性诊断。不能可靠断定某一良性病种是主要误报来源。

## 建议下一步
1. 优先做原权重的受控稳定性检查：保持病灶有效像素和阈值不变，只替换填充区域，观察不同来源、FP/FN/TP/TN的分数变化。该步骤不需要重新训练。
2. 若证据支持边框或拍摄风格依赖，再设计一项预处理/增强对照；每次只改变一项，同时报告整体及分来源的表现。
3. 若未发现明确的背景依赖，再考虑以更低学习率解冻更多层；改进后用另一随机种子重复，不凭一次实验作结论。
暂不优先追加患者未知的2019数据，不凭模型错误删除样本、不改标签、不按来源手工调整标签，也不使用测试集来选择方案。
